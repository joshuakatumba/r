# Cross-Border Internal Transfer System — Presentation Guide

## What is this project?

This is an internal money transfer system built for a company that has branches in Uganda and Sudan. When a customer hands over money in one branch, the other branch needs to know about it instantly so they can pay out the receiver. That is the core of what this system does.

There are three separate login portals:

Uganda Branch — for tellers in Uganda

Sudan Branch — for tellers in Sudan

Admin Center — for managers who oversee everything


## The Problem We Are Solving

Before this system, companies like this relied on phone calls, WhatsApp messages or spreadsheets to coordinate between branches. Codes get lost in chats. Records can be edited. Management has no visibility into what is happening. If the same code is shared twice by mistake the company pays out the same money twice.

This system keeps everything in one place under full management control.


## Why Not Just Use a Bank?

Banks are fine for customers but not practical for internal operations between company branches. A bank transfer can take a day or more to reflect and costs money per transaction. This system is instant and internal with no third party involved and no fees.


## How the System Works

A customer walks into the Uganda branch and deposits money. The teller logs in and creates a transfer. The system generates a unique code and a receipt. That code is given to the customer.

The customer's recipient walks into the Sudan branch with that code. The Sudan teller looks it up. The system confirms the details and the teller releases the funds. Once released the code is locked forever and cannot be used again.


## Security and Staff Access

New employees sign up on the branch portal. Their accounts are locked until a manager manually approves them from the Admin Center. This means no unauthorized person can ever access the system.

Managers see every transaction from both branches in real time on one dashboard.
